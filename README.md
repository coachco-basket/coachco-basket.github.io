# CoachCo

Application pour préparer ses entraînements de basket : cycles, séances, CEC, bibliothèque d'exercices et de matchs à thème, schémas sur parquet et projet pédagogique.

Ouvrir l'appli : https://coachco-basket.github.io/

Les données restent sur le téléphone de chaque coach (pensez à la sauvegarde dans les réglages).
